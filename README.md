The GPS's one-line excuse for sending the driver down the wrong road, in its own smug voice: **"The map promised a bridge, the lake vetoed it, and the wedding needed a dramatic entrance — so I delivered you, fashionably late, by water."** The map is blamed, the lake gets the last word, and the detour is presented as a favour.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (no trailing newline) and prints it to stdout. Deterministic, standard library only, no network.
